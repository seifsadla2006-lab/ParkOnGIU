# ParkOnGIU
ParkOnGIU is Team 39’s campus parking project. It helps GIU students see where a parking spot recently opened
GIU students can lose time before class driving through unmarked parking rows and checking the same rows again. ParkOnGIU is a shared map that helps them decide where to look first. Students mark where they park and check out when they leave, so other drivers can see where a spot recently opened.

## Features

- Parking Map
- Pin My Spot
- Free Up My Spot
- Report Spot Taken
- Find My Car
- Leaving Soon
- Past Parking Sessions
